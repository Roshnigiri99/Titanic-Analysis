# Titanic Dataset Analysis

## Overview

This project analyzes the Titanic dataset to explore the factors that influenced passenger survival. The dataset contains information about passengers such as their age, gender, ticket fare, passenger class, and more. The analysis includes data cleaning, visualization, and interpretation of patterns and trends.

## Dataset Used

- `train.csv` – Training dataset with passenger information and survival status.
- `test.csv` – Test dataset with passenger information only.
- `gender_submission.csv` – Sample submission file with predicted survival outcomes.

## Objectives

- Perform exploratory data analysis using pandas and seaborn.
- Visualize distributions and relationships using histograms, boxplots, scatterplots, pairplots, and heatmaps.
- Identify key factors influencing survival.
- Provide a written summary of insights and conclusions.

## How to Use

1. Open the Jupyter Notebook or Google Colab.
2. Upload the CSV files using the file panel.
3. Run the analysis code cells sequentially.
4. Review the visual outputs and refer to the Word report for detailed explanations.

## Summary of Findings

- Female passengers had a higher survival rate.
- Passengers in 1st class survived more often than those in lower classes.
- Younger passengers and those who paid higher fares were more likely to survive.
- Embarkation point and family size showed minor but notable trends.
